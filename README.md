# Report-saham

نسخه اول برنامه اندرویدی مدیریت معاملات ۶ سهامدار.

## امکانات نسخه اول
- ثبت خرید و فروش
- ثبت نماد، تعداد، قیمت و تاریخ
- ذخیره محلی SQLite
- گزارش CSV سازگار با Excel
- گزارش PDF
- ساخت خودکار APK با GitHub Actions

## Build
GitHub Actions با Java 17 و Gradle 8.9 پروژه را build می‌کند.
